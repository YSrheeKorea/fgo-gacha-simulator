**Fate/Grand Order(FGO)**의 소환 연출, 실제 확률·330연 천장, 한그오 공식 일러스트·대사·프로필, 마이룸 육성, 폭사력 통계 및 **모바일 PWA 앱 설치**를 지원하는 순수 HTML/CSS/JS 웹 게임입니다.

## ✨ 주요 기능
- **원작 FGO 소환실 가챠 연출**: 3D 투시 바닥 마법진, 빛기둥, 3광구 3중 회전(일반 / 금색 회전 / 무지개 회전), 은테→금테 치직 전격 승격, 원작 FGO 스타일 타자기 대사창
- **공식 확률 & 천장 고증**: ★5 서번트 1%(픽업 0.8% / 픽뚫 0.2%), ★4 서번트 3%, 11연(10+1) 확정 룰, 단차 10+1 보너스, 배너별 330연 천장, 상시·스토리 해금·기간 한정 풀 분리
- **45기 서번트 & 28종 개념예장 & 10개 배너**: Atlas Academy KR 공식 일러스트(1~4차 재림) & 한그오 공식 소환/마이룸 대사·프로필·스킬·보구·개념예장 해설 반영
- **영기 일람 · 마이룸 · 다 빈치 공방**: 1~4차 영기재림, 성배전림(Lv.120), 인연 Lv.15(몽화 보너스), 보구 Lv.5·무기명 영기(USO), 마프/레프 교환소 및 무료 성정석 충전 시뮬레이션
- **가챠 통계 & 폭사력 분석 · ⚙️ 설정 탭**: 실제 확률 비교, 현질 환산 트럭 수, 운세 등급(`EX`~`E-`), 연출 속도/볼륨/타자기 속도 설정, 원작 연출 4종 미리보기 테스트, JSON 세이브 내보내기/불러오기
