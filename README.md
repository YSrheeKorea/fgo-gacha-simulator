## ✨ 핵심 기능 요약

### 1. 성정석 소환 (원작 FGO 소환실 고증)
- **원작 소환 연출**: 3D 투시 바닥 마법진, 빛기둥, 3광구 3중 회전(일반 / 금색 회전 / 무지개 회전), 은테→금테 **치직 전격 승격**, 원작 FGO 스타일 타자기 대사창
- **공식 확률 & 천장**: ★5 서번트 1%(픽업 0.8% / 픽뚫 0.2%, 픽뚫 시 천장 미초기화), 11연(10+1) 확정 룰, 단차 10+1 보너스, 배너별 **330연 천장**, 상시 / 스토리 해금(환상종) / 기간 한정 풀 완전 분리
- **10종 배너 · 45기 서번트 · 28종 개념예장**: Atlas Academy KR 공식 일러스트(1~4차 재림) + 한그오 공식 원문 대사·프로필·개념예장 해설

### 2. ⚔️ FGO 커맨드 카드 배틀 (6인 편성 · B/A/Q)
- **6인 파티 편성**: 본인 서번트 5명 + 프렌드 서포트 1명 (전열 3명 출격 · 사망 시 후열 자동 증원)
- **커맨드 카드 & 체인 7종**: 서번트별 실제 공식 5장 커맨드 덱(`Q/A/B`), 버스터(1.5/1.8/2.1배·자체 NP 0)/아츠(1.0배)/퀵(0.8배), 버스터/아츠/퀵(+20스타)/마이티/브레이브/마이티 브레이브 체인 및 `EXTRA ATTACK`
- **보구 & 오버차지 & 오버킬**: 보구 레벨별 NP 상한(100/200/300%), 100% 단위 절사, 보구 체인 OC +100%/+200%, 크리티컬×오버킬 곱연산, 스타 50개 이상 100% 크리티컬 확정
- **완벽 상성 & 히든 속성**: 16×16 클래스 상성(비스트Ⅰ·Ⅱ·Ⅲ/R 포함) + 공격측 클래스 보정치 + 5×5 히든 속성(`천/지/인/성/수`) + 적 클래스별 NP 획득률 보정(`캐·문 1.2× / 라 1.1× / 어 0.9× / 버 0.8×`)
- **영주 3획 & 전투 이어하기**: 매일 0시 3획 자동 회복(`영기수복` / `보구해방` / 전멸 시 `영기복원` + 성정석 1개 부활), 중단된 전투 자동 저장 & 재접속 이어하기
- **7종 퀘스트**: 종화 수집, 보물고 QP, 흑화 세이버, 바빌로니아 티아마트(비스트Ⅱ), 마신왕 게티아(비스트Ⅰ), 셋쇼인 키아라(비스트Ⅲ/R), 이문대 케르눈노스 EX

### 3. 영기 일람 · 마이룸 육성 · 다 빈치 공방 · 통계 · ⚙️ 설정
- **마이룸 육성**: 1~4차 영기재림(공식 QP), 성배전림(Lv.120), **스킬 Lv.1~10 강화(공식 QP 표 · Lv.6 쿨-1T / Lv.10 쿨-2T)**, 인연 Lv.1~15(몽화 보너스 성정석 +30)
- **다 빈치 공방 & 통계**: 보구 Lv.5 · 무기명 영기(USO), 마프/레프 교환소, 일괄 영기 변환, 현질 환산 트럭 수·폭사 등급(`EX`~`E-`) 분석
- **⚙️ 설정 탭**: 연출 속도, ★3 중복 자동 스킵, 효과음 볼륨, FGO 대사창 타자기 속도, 원작 연출 4종 무료 미리보기, JSON 세이브 백업/복원, PWA 앱 설치
